# WWE Champions Dashboard

A single-repository dashboard for current WWE champions. The frontend reads a local cache at `public/champions.json`; the cache is generated by `scrape.py`, which aggregates WWE.com champion data with Cagematch title metadata.

## Tech Stack

- Frontend: Vite, React, TypeScript, Tailwind CSS
- Scraper: Python, Playwright, BeautifulSoup
- Data cache: `public/champions.json`
- CI credential inventory: [`docs/keys.md`](docs/keys.md)

## Prerequisites

- Node.js 20+
- Python 3.11+
- Chromium installed through Playwright

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r .github/requirements-scraper.txt
python -m playwright install chromium
npm install
```

## Generate Champion Data

GitHub Actions runs this automatically every Tuesday at 08:00 UTC. If the scrape changes generated data, it opens a pull request as `gh-omp[bot]` rather than pushing directly to `main`. Review and merge the PR after the required checks pass; the dashboard's static data updates when that merge deploys.

To refresh manually:

```bash
source .venv/bin/activate
python scrape.py
```

The scraper writes the champion array to `public/champions.json` and the completed refresh time to `public/metadata.json`. The dashboard displays that generated time when available; if the metadata cannot be read, it marks the update time unavailable while keeping valid champion records visible.

If Cagematch is unavailable or blocks a request, the script still preserves WWE.com champion records with display-safe fallback values.

## Run the Dashboard

```bash
npm run dev
```

Then open the local URL printed by Vite, usually `http://localhost:5173`.

Use **Reload snapshot** to read the available snapshot again without running an upstream scrape. Loading, empty snapshots, and failures have reader-facing messages. A persistent polite status region announces completed record counts and failures; successful retries are announced even when the count is unchanged. A failed reload preserves the previous usable snapshot.

```json
    "wweUrl": "https://www.wwe.com/...",
    "cagematchUrl": "https://www.cagematch.net/..."
  }

```

## Scraper Notes

- WWE.com is parsed from its public superstar/champion listing and champion profile pages.
- Cagematch is loaded with Playwright because it commonly serves a JavaScript gate to non-browser clients.
- Names and titles are normalized for accents, punctuation, curly apostrophes, ampersands, casing, and whitespace.
- The scraper matches exact normalized titles first, then falls back to fuzzy title and champion similarity.
- Missing title defenses are represented as `No Title Defenses Yet` in the JSON and UI.
